白狼ましろ公式サイト｜LIVE表示プレビュー

通常の index.html：LIVE表示は非表示（配信状況の自動取得は未接続）
index.html?live_test=on：LIVE表示の見た目をテスト
index.html?live_test=off：非表示をテスト

注意：ローカルのfile://環境ではJSON取得が制限される場合があります。公開時にはHTTPS上で動作します。
自動判定にはYouTube Data APIの設定、定期更新処理、公開先の設定が別途必要です。
配信中かどうかを偽って表示しないよう、取得失敗や古いデータの場合は非表示にします。
既存の画像・プロフィール・肉球・ふよふよ演出は維持しています。
